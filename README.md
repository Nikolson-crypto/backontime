# Backontime — приложение против парковочных штрафов (Дания)

## Что это

Мобильное веб-приложение (PWA) для водителей Копенгагена: отметить, где стоит машина,
задать лимит парковки (P-skive, оплачено до, правила зоны) и вовремя получить сигнал
«пора идти», с учётом реального времени ходьбы до машины. Цель — не получать штрафы
(510 DKK муниципальный, 510–750 DKK частный).

Выросло из PWA «Назад вовремя» (вернуться к точке встречи вовремя) — механика та же.
Прод текущей версии: https://nikolson-crypto.github.io/backontime/

## Структура

| Путь | Что там |
|---|---|
| `index.html` | разметка обоих экранов (настройка, отслеживание) |
| `src/app.js` | вся логика: геолокация, маршрут OSRM, таймеры, сигналы, компас, карта, ссылка |
| `src/style.css` | стили |
| `manifest.json`, `icon.svg` | PWA |
| `docs/architecture.md` | архитектура: что есть, что переиспользуем, целевая структура |
| `docs/adr/` | принятые архитектурные решения (ADR) |
| `.claude/handoff.md` | рабочий журнал сессий (не в git) |

После эпика E0 (см. план) код переезжает в модули `src/`, появляются `tests/` и сборка Vite.

## Как запустить

Сборки пока нет, это статический сайт:

```bash
cd ~/Projects/backontime
python3 -m http.server 8080
```

Открыть http://localhost:8080 — должен появиться экран «Отметить здесь».
На телефоне для GPS нужен https: проще открыть прод-ссылку выше.

Секретов пока нет. После подключения Supabase (ADR-002) ключи будут в `.env`
(в `.gitignore`), пример — в `.env.example`.

Деплой: `git push` в `main` → GitHub Pages обновляется за 1–2 минуты.
