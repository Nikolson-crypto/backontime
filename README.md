# Backontime — приложение против парковочных штрафов (Дания)

## Что это

Мобильное веб-приложение (PWA) для водителей Копенгагена: отметить, где стоит машина,
задать лимит парковки (P-skive, оплачено до, правила зоны) и вовремя получить сигнал
«пора идти», с учётом реального времени ходьбы до машины. Цель — не получать штрафы
(510 DKK муниципальный, 510–750 DKK частный).

Выросло из PWA «Назад вовремя» (вернуться к точке встречи вовремя) — механика та же.
Прод текущей версии: https://nikolson-crypto.github.io/backontime/

## Структура

| Путь | Что там |
|---|---|
| `index.html` | разметка обоих экранов; тексты помечены `data-i18n` |
| `src/main.js` | точка входа: язык, переводы, восстановление сессии |
| `src/i18n/` | переводы `ru.json`, `en.json`, `da.json` (датский пока = английский, заполняется в E5) и функция `t()` |
| `src/parking/` | `limits.js` — расчёт лимита, времени выхода и статуса (чистые функции); `session.js` — форма сессии, хранение, ссылка «поделиться»; `history.js` — последние 10 парковок |
| `src/geo/` | GPS, маршрут OSRM с фолбэком, азимут |
| `src/alerts/` | локальный сигнал: звук, вибрация, уведомление |
| `src/map/` | карта Leaflet, слои Схема/Спутник |
| `src/ui/` | экраны настройки и отслеживания, `setup-limit.js` — выбор типа лимита, `setup-history.js` — карточка последних парковок, `setup-map.js` — карта уточнения места машины, компас, форматирование |
| `src/style.css` | стили |
| `public/` | `manifest.json`, `icon.svg` — копируются в сборку как есть |
| `tests/` | Vitest: расчёты лимита и статусов, азимут, сессия и ссылки, история, переводы |
| `.github/workflows/` | CI: тесты на PR; сборка и деплой на Pages из `main` |
| `docs/architecture.md` | архитектура: что есть, что переиспользуем, целевая структура |
| `docs/adr/` | принятые архитектурные решения (ADR) |
| `.claude/handoff.md` | рабочий журнал сессий (не в git) |

## Как запустить

```bash
cd ~/Projects/backontime
npm install        # один раз
npm run dev        # локальный сервер
```

Открыть адрес из терминала (обычно http://localhost:5173/backontime/) — появится экран «Отметить здесь».
Язык берётся из настроек телефона (ru / en / da), иначе английский.
На телефоне для GPS нужен https: проще открыть прод-ссылку выше.

Проверка перед коммитом:

```bash
npm test           # тесты Vitest
npm run build      # сборка в dist/
```

Секреты — в `.env` (в `.gitignore`), пример в `.env.example`. Сейчас там один ключ:
`VITE_CARTO_KEY` для карт CARTO (бесплатно на https://carto.com/basemaps/apikey); без него
схема берётся с OpenStreetMap. На GitHub тот же ключ хранится в секретах репозитория.

Деплой: `git push` в `main` → GitHub Actions собирает и выкладывает на Pages за 1–2 минуты. Ветки и PR прогоняют только тесты.
