# ADR-001. Остаёмся на PWA для этапа валидации

Дата: 15.09.2026. Статус: принято.

## Контекст
Главная ценность продукта — напоминание, когда приложение закрыто и телефон в кармане.
iOS не выполняет JS веб-страницы в фоне; текущая версия сигналит только при открытой странице.

## Решение
Первые 6 месяцев (валидация) — PWA. Фоновые напоминания реализуем через Web Push
(iOS ≥ 16.4 при добавлении на экран «Домой», Android — везде) с сервером расписания.
Онбординг обязан объяснить установку на экран «Домой».

## Почему
- Уже есть работающий код и бесплатный хостинг; выпуск без магазинов и без ожидания ревью.
- Web Push закрывает ключевой сценарий; ограничение — только для тех, кто не установил на экран.
- Нативное приложение (React Native / Capacitor) — заметно дороже и не нужно, пока не доказан спрос.

## Последствия
- Метрика в бете: доля пользователей, установивших на экран «Домой», и доля доставленных push.
- Если по итогам валидации фоновые ограничения iOS реально мешают, оборачиваем в Capacitor
  (код остаётся тот же) — пересмотр ADR в месяц 6.
