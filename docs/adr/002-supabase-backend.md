# ADR-002. Бэкенд — Supabase

Дата: 15.09.2026. Статус: принято (выбор пользователя: Supabase вместо своего сервера на Hetzner).

## Контекст
Нужны: расписание и отправка Web Push, анонимные аккаунты устройств, кэш зон, позже
подписки и B2B-аккаунты. Сервера у проекта нет.

## Решение
Supabase (Postgres + Auth + Edge Functions + cron). Фронт остаётся на GitHub Pages.
Ключи — в `.env` (anon key в фронте допустим по правилам Supabase, service key — только в edge-функциях).
Row Level Security включена с первой таблицы.

## Почему
- Быстрый старт без администрирования; бесплатного плана хватает на валидацию.
- Auth даёт анонимные и позже email/Apple/Google-аккаунты без своего кода.
- Edge Functions + pg_cron закрывают расписание push.

## Последствия
- Зависимость от одного провайдера; данные экспортируемы (Postgres), риск приемлем.
- Переезд на Hetzner возможен позже, если платный план станет дороже своего сервера.
