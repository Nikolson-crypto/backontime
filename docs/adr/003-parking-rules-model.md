# ADR-003. Правила парковки: зоны как полигоны, каждое правило — с источником и датой

Дата: 15.09.2026. Статус: принято.

## Контекст
Риск №1 из исследования — ответственность за неверную подсказку («приложение сказало
можно, а штраф пришёл»). Зоны и тарифы меняются (реформа Копенгагена 2025: воскресная оплата,
новые тарифы). Данные: Open Data DK `kbh_p_zoner` (CC0), правила — borger.dk.

## Решение
- Зона = полигон GeoJSON + список правил. Правило = дни, часы, тариф, лимит P-skive, примечание.
- У каждой зоны и правила обязательные поля `source_url` и `source_date`; интерфейс показывает
  «Источник: …, обновлено ДД.ММ.ГГГГ» рядом с любой подсказкой.
- Версионирование: обновление зон не перезаписывает, а создаёт новую версию; активная сессия
  ссылается на версию, по которой считался лимит.
- Дисклеймер при онбординге и на экране лимита: приложение помогает, ответственность на водителе.
- Никакого «здесь можно бесплатно» без правила с источником; при отсутствии правила — «правило
  неизвестно, проверьте знак».

## Последствия
- Ручной ввод тарифов с ссылками — часть эпика E6; еженедельный скрипт сравнения данных.
- Подготовлена почва для других городов: та же модель, другой источник.
